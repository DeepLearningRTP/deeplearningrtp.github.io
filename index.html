Live demo · nothing leaves your device

Machine learning, running in this tab.

No server, no API keys, no uploads. The models below download to your browser and run on your own hardware, and each demo ties to something the group has worked through on a Wednesday. Click one to load it (first run fetches the model).

Transformers.js · SmolLM2-135M ~137MB

Next-token explorer

A language model never writes a sentence. It scores every token it knows, one step at a time. Type a prompt, see how it gets cut into tokens, then pick the next one yourself.

What's happening here?

Your text is split into tokens (the boxes): common words are one token, rare ones get chopped up. The model reads them all and outputs one score for each of its 49,152 vocabulary entries. Softmax turns the scores into the probabilities you see. Temperature divides the scores before softmax: low makes the top pick dominate, high flattens the field. Chat models do exactly this loop, thousands of times per reply.

Deeper: Karpathy's Let's build the GPT Tokenizer and the Build an LLM (From Scratch) repo.

Plain arithmetic · no download

Will it fit? The KV-cache calculator

Serving a model means holding its weights and a cache of keys and values for every token in every conversation. Pick a model and a workload and see where the memory goes.

What's happening here?

Each layer stores a key and a value vector for every token so the model doesn't recompute the past. That cache grows with context × users, and at long context it outweighs the model itself. The architectures we've surveyed attack it directly: grouped-query attention (Llama 3, Mixtral) shares one key/value head across several query heads; DeepSeek's multi-head latent attention caches one small compressed vector instead. Mixture-of-experts models are the opposite trade: huge weights, but each token only runs through a slice of them.

Numbers ignore activations and framework overhead, so real headroom is a bit smaller. Deeper: GQA, DeepSeek-V2 (MLA), and How to Scale Your Model.

Transformers.js · MiniLM ~23MB

Has the group covered that? Search 396 meetings

Every session from 2017 to 2024, searched by meaning rather than keywords. Try "protein folding", "playing games with RL", or "making art with neural nets".

What's happening here?

Each meeting's title and description was turned into a 384-number vector (an embedding) ahead of time. Your query gets the same treatment, here in your browser, and results are ranked by cosine similarity: how closely the two vectors point the same way. That's why a search can find "Minigo" for "playing games with RL" without the words matching. This is the retrieval half of every RAG system.

WebLLM · WebGPU

Chat with a language model — 100% local

Runs a small instruct model entirely on your machine via WebGPU. First launch downloads the weights (~400MB–900MB, then cached). Zero servers, zero API keys.

What's happening here?

The "q4f16" in the model name means the network's weights are quantized to 4 bits; that's how a billion-parameter model fits in browser memory. Replies are generated one token at a time; the streaming you see is the real generation loop, and the tokens/sec readout is your own hardware's inference speed.

Want to build one? Raschka's Build an LLM (From Scratch) and Karpathy's Zero to Hero are both on the list above.
